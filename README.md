# PPT Skills

Reusable presentation design expertise for PPT Master.

## Professional Marketing Presentation Style

[Marketing Presentation Style](Marketing-Presentation-Style.md) is one unified, reusable design specification distilled from the full supplied marketing reference corpus. It preserves transferable design judgment rather than copying brand identities or exact slide layouts.

Use the complete specification as a reference when briefing an authoring agent or designing a presentation. Apply its communication logic, hierarchy, typography, image treatment, data presentation, deck rhythm, and review criteria to the new brief. The specification is standalone; the original references are not required.

## Let another agent apply the Style

Read the documents in this order:

1. [Marketing Presentation Style](Marketing-Presentation-Style.md): the full governing specification.
2. [Agent Quickstart](docs/Agent-Quickstart.md): a portable instruction to copy, brief inputs, semantic calibration, and the working record.
3. [Worked Examples](docs/Worked-Examples.md): eight fictional cases with weak approaches, design decisions, rationales, constraint changes, and three paired teaching diagrams.
4. [Transfer Checks](docs/Transfer-Checks.md): hard acceptance gates, an anchored review rubric, and four unfamiliar briefs to test adaptation.

[AGENTS.md](AGENTS.md) gives repository-aware agents the same entry path. Agents that do not load that file can use the portable instruction from the quickstart and receive the required documents as attachments. Reading these files gives an agent usable guidance; quality still depends on interpreting the brief, rendering the work, and repairing observed defects.

Copy the decision logic from the examples, then compose for the new argument. The teaching facts, wording, palettes, and arrangements are not defaults. The teaching diagrams are explanatory schematics, not a generated presentation or a second template system.

The [cumulative study notes](marketing-style-study/cumulative-notes.md) record 44 contiguous batches covering all 2,078 PDF pages, additional closer review, cumulative principles, and limitations. PDF pages are not a verified count of unique slides.

This repository contains the design specification and research record. It does not contain a generated presentation, a PowerPoint master file, or an installed Codex skill. The source PDF, extracted images, and proprietary reference assets are excluded.
